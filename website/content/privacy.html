Analytics privacy

The published Parlora blog uses Cloudflare Web Analytics to measure visits and browser performance.

It shares the hfiguera.github.io analytics property with the maintainer’s other project blogs. Parlora’s traffic can be viewed separately by filtering page paths beginning with /parlora/.

Cloudflare describes Web Analytics as a service that does not use cookies, local storage, or fingerprinting to track visitors. We do not send code copies, walkthrough interactions, or article content as custom analytics events.

The script loads from static.cloudflareinsights.com and sends measurements to cloudflareinsights.com. The blog remains readable and its examples work if the script is blocked. Local previews omit analytics by default.

These measurements describe visits to this blog. They do not establish whether someone installed or used Parlora.

For details, read Cloudflare’s privacy approach and data collection documentation.
